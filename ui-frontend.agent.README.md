# UI Frontend Agent

This agent is built for UI and frontend development questions.

## Purpose
Use this agent whenever you need help with:
- WinForms and desktop form design
- WPF, XAML, MVVM, styles, templates
- Web frontend development (HTML, CSS, JavaScript, TypeScript, React, Angular, Vue)
- UI/UX design, layout, accessibility, responsive interfaces

## How to use
- Ask UI-specific questions like:
  - "Làm sao tạo ListView trong WinForms?"
  - "Cách binding dữ liệu trong WPF MVVM?"
  - "Thiết kế responsive layout bằng CSS Grid/Flexbox"
- If your question is not UI-related, this agent will let you know and recommend another specialist.

## Notes
- The agent is optimized for interface design and frontend implementation.
- It should return code examples and practical guidance rather than generic theory.
